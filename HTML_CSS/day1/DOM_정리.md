# DOM (Document Object Model) 정리

## DOM이란

DOM(Document Object Model, 문서 객체 모델)은 브라우저가 HTML 문서를 해석해 메모리 안에 만들어내는 트리 구조다. `.html` 파일 자체는 그냥 텍스트지만, 브라우저가 이 텍스트를 파싱하면 각 태그가 하나의 객체(노드)가 되고, 태그의 중첩 관계가 그대로 부모-자식 트리로 표현된다.

```html
<body>
  <h1>제목</h1>
  <p>내용</p>
</body>
```

위 HTML은 브라우저 내부에서 다음과 같은 트리로 표현된다.

```text
body
├── h1 (텍스트: "제목")
└── p  (텍스트: "내용")
```

## HTML과 DOM은 다르다

HTML 소스 코드는 브라우저가 화면을 그리기 위한 "설계도"이고, DOM은 그 설계도를 바탕으로 브라우저가 실제로 메모리에 구성한 "결과물"이다. 개발자 도구의 Elements 탭에서 보이는 것은 원본 HTML 파일이 아니라 현재 시점의 DOM 상태이며, JavaScript로 노드를 추가·삭제·수정하면 원본 `.html` 파일은 그대로여도 화면(DOM)은 바뀐다.

| 구분 | HTML | DOM |
|---|---|---|
| 정체 | 텍스트 파일(소스 코드) | 브라우저 메모리 안의 객체 트리 |
| 시점 | 정적, 최초 작성 시점 그대로 | 동적, JavaScript로 실시간 변경 가능 |
| 확인 방법 | 소스 보기(우클릭 → 페이지 소스 보기) | 개발자 도구 Elements 탭 |

## JavaScript로 DOM 다루기

JavaScript는 DOM을 조작해 화면을 동적으로 바꾸는 데 쓰인다. 대표적인 접근·조작 방법은 다음과 같다.

| 목적 | 메서드/속성 | 설명 |
|---|---|---|
| 요소 찾기 | `document.querySelector(선택자)` | CSS 선택자 문법으로 요소 하나를 찾음 |
| 요소 찾기(여러 개) | `document.querySelectorAll(선택자)` | 조건에 맞는 모든 요소를 목록으로 반환 |
| 텍스트 변경 | `element.textContent` | 요소 안의 텍스트 내용을 읽거나 바꿈 |
| 속성 변경 | `element.setAttribute(이름, 값)` | 태그의 속성값을 바꿈 |
| 요소 추가 | `document.createElement(태그명)` + `appendChild()` | 새 노드를 만들어 트리에 추가 |
| 요소 삭제 | `element.remove()` | 트리에서 해당 노드를 제거 |
| 이벤트 연결 | `element.addEventListener(이벤트, 함수)` | 클릭 등 사용자 동작에 반응하는 함수를 연결 |

## 왜 DOM 개념이 중요한가

정적인 HTML만으로는 "버튼을 누르면 목록에 항목이 추가된다"처럼 사용자 행동에 반응하는 화면을 만들 수 없다. DOM은 이런 상호작용의 기반이 되는 구조로, JavaScript가 실제로 무엇을 읽고 무엇을 바꾸는지가 결국 DOM 트리라는 점을 이해해야 이후 이벤트 처리·화면 갱신 로직을 정확히 다룰 수 있다. React 같은 프레임워크의 "가상 DOM(Virtual DOM)" 개념도, 실제 DOM을 직접 조작하는 대신 변경 사항을 비교해 필요한 부분만 반영하는 최적화 기법으로, DOM의 기본 구조를 알아야 그 차이가 이해된다.
