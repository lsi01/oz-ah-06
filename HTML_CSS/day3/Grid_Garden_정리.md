# Grid Garden 정리 (cssgridgarden.com)

28개 스테이지를 모두 직접 풀면서, CSS Grid 속성을 단계별로 정리했다.
Flexbox Froggy가 "1차원 정렬"(가로 또는 세로 한 줄)을 다뤘다면, Grid Garden은 **행(row)과 열(column)을 동시에 다루는 2차원 배치**를 연습하는 게임이다.

## 전체 요약표

| 단계 | 사용 속성 | 핵심 개념 |
|---|---|---|
| 1~2 | `grid-column-start` | 특정 세로선(번호)에서 시작해 폭 1칸짜리 영역 지정 |
| 3~4 | `grid-column-start` + `grid-column-end` | 시작~끝 세로선을 지정해 폭 확장 (end가 start보다 작아도 됨) |
| 5~6 | 음수 인덱스 | 세로선을 오른쪽 끝 기준(-1, -2, ...)으로 지정 |
| 7~9 | `span` 키워드 | "몇 칸 만큼" 폭을 지정 (`grid-column-end: span 2`) |
| 10 | `grid-column` 단축 속성 | `start / end`를 한 줄로 (`grid-column: 4 / 6`) |
| 11 | `grid-column` + `span` | `2 / span 3`처럼 단축 속성 안에서도 span 사용 가능 |
| 12~13 | `grid-row`, `grid-row-start` | 세로축(행) 버전 — column과 동일한 규칙 |
| 14~15 | `grid-column` + `grid-row` 동시 사용 | 가로·세로를 동시에 지정해 정확한 셀/영역 특정 |
| 16 | `grid-area` (4값 단축) | `row-start / col-start / row-end / col-end` 한 번에 |
| 17 | 겹치는 영역 | 여러 `grid-area`가 겹쳐도 문제 없음 — 겹치는 셀은 두 번 물 줘도 무방 |
| 18~19 | `order` | 그리드에서도 flexbox처럼 소스 순서 대신 배치 순서를 재정의 |
| 20~22 | `grid-template-columns` 커스텀 값 | %, `repeat()`, px/em 등 다양한 단위 혼합 |
| 23~25 | `fr` 단위 | 고정 크기(px 등)를 제외한 "남은 공간"을 비율로 분배 |
| 26 | `0` 크기 트랙 | 트랙 개수를 맞추되 일부를 0으로 접어 원하는 만큼만 보이게 함 |
| 27 | `grid-template` 단축 속성 | `rows / columns`를 한 줄로 (`60% 40% / 200px auto`) |
| 28 (최종) | 종합 | 고정 위치의 물/독 요소에 맞춰 `grid-template-columns`·`grid-template-rows`를 역산 |

## 스테이지별 상세 메모

### 1~4단계: 세로선(vertical line) 번호로 위치 지정
Grid는 칸이 아니라 **칸과 칸 사이의 선(line)**에 번호를 매긴다. 5개 열이면 세로선은 1~6번까지 존재.
- `grid-column-start: 3` → 3번 선에서 시작하는 폭 1칸짜리 영역
- `grid-column-end`를 함께 쓰면 시작~끝 선을 지정해 폭을 넓힐 수 있고, **end가 start보다 작은 숫자여도 상관없다** (브라우저가 알아서 더 작은 쪽을 시작으로 처리).

### 5~6단계: 음수 인덱스
왼쪽(1번선) 기준이 아니라 **오른쪽 끝(-1번선) 기준**으로 셀 수 있다. 5열 그리드는 선이 6개(1~6)이므로 `-1`=6번선(맨 오른쪽), `-2`=5번선, ... `-6`=1번선(맨 왼쪽)이 된다. 반응형 레이아웃에서 "마지막에서 두 번째 칸"처럼 열 개수가 변해도 상대적으로 위치를 잡을 때 유용하다.

### 7~9단계: span 키워드
`grid-column-end: span 2`처럼 쓰면 "정확히 몇 번째 선까지"가 아니라 **"몇 칸만큼 차지할지"**를 지정할 수 있다. 시작 위치만 알고 정확한 끝 선 번호를 계산하기 귀찮을 때 편리하다. `grid-column-start`에도 `span`을 쓸 수 있어 `grid-column-end` 기준으로 거꾸로 계산할 수도 있다.

### 10~11단계: grid-column 단축 속성
`grid-column: 시작 / 끝;` 한 줄로 `-start`/`-end` 두 속성을 대체할 수 있다. `grid-column: 2 / span 3`처럼 슬래시 뒤에 `span`을 섞어 쓰는 것도 가능.

### 12~15단계: grid-row와 2차원 지정
`grid-row`, `grid-row-start`는 세로축(행) 버전으로 동작 원리는 column과 완전히 동일하다. `grid-column`과 `grid-row`를 **동시에** 지정하면 그리드 안의 정확한 사각 영역(가로 범위 × 세로 범위) 하나를 특정할 수 있다.

### 16~17단계: grid-area
`grid-area: row-start / column-start / row-end / column-end;` 형태로 행·열 시작/끝을 한 번에 지정하는 가장 축약된 문법. 여러 요소의 `grid-area`가 서로 겹치도록 설정해도 문제없다 — 겹치는 칸에 물을 두 번 준다고 해서 잘못되는 게 아니라, **아직 물 안 준 당근 칸을 전부 포함하기만 하면** 정답으로 인정된다. 다만 실제로 검증해보니 "겹쳐도 되는 여유"는 있지만 **각 물 요소가 정확히 특정 당근 영역과 grid-area 값이 일치해야** 하는 경우도 있어(17단계 두 번째 영역), 처음엔 넉넉하게 잡았다가 "다음" 버튼이 활성화되지 않는 걸 보고 실제 당근 영역의 `gridColumn`/`gridRow` 계산값에 맞춰 정확히 좁혀 맞췄다.

### 18~19단계: order
Flexbox Froggy에서 배운 `order`가 Grid에도 그대로 적용된다. 명시적인 `grid-column`/`grid-row` 없이 자동 배치(auto-placement)되는 요소들은 **소스 순서 대신 `order` 값 순서대로** 칸에 채워진다. 값이 작을수록 앞쪽(왼쪽/위쪽) 칸을 차지한다.

### 20~22단계: grid-template-columns 커스텀 값
- 퍼센트를 다르게 섞어 쓸 수 있다 (`50% 20% 20% 20% 20%` — 합이 100%를 넘어도 게임 상에서는 그대로 렌더링됨).
- 같은 값이 반복되면 `repeat(개수, 크기)` 함수로 축약 가능 (`repeat(8, 12.5%)` = `12.5%`가 8번).
- `px`, `em`, `%`를 한 줄 안에서 자유롭게 섞어 쓸 수 있다 (`100px 3em 40%`).

### 23~25단계: fr 단위
`fr`(fraction)은 **"고정 크기 트랙들을 제외하고 남은 공간"을 비율로 나누는 단위**다. `1fr 5fr`이면 남은 공간을 1:5로 분배하고, `50px ... 1fr 1fr 1fr ... 50px`처럼 고정폭(px) 트랙과 섞어 쓰면 양 끝은 고정폭, 가운데는 균등하게 늘어나는 반응형 레이아웃을 만들 수 있다.

### 26단계: 트랙을 0으로 접기
문제에서 "정확히 N개의 트랙을 만들어야 한다"는 제약이 있을 때, 실제로 보이길 원하는 트랙 수보다 트랙을 많이 만들어야 하는 경우가 있다. 이때 필요 없는 트랙은 크기를 `0`으로 주면 시각적으로는 사라지고, 원하는 트랙만 `1fr` 등으로 남은 공간을 전부 차지하게 만들 수 있다 (`50px 0 0 0 1fr` → 위 50px + 아래는 사실상 하나의 큰 영역처럼 보임).

### 27단계: grid-template 단축 속성
`grid-template: <행 크기 목록> / <열 크기 목록>;` 형태로 `grid-template-rows`와 `grid-template-columns`를 한 줄로 합칠 수 있다 (`60% 40% / 200px auto`).

### 28단계 (최종): 종합 문제
이 단계는 편집기에 `#garden {}` 블록 하나만 있고 물/독을 담당하는 요소는 별도로 노출되지 않았다 — 즉 물/독 요소의 위치는 이미 고정되어 있고, **그 고정된 위치가 원하는 그림이 되도록 그리드의 트랙 크기 자체를 거꾸로 설계**해야 하는 문제였다.

조건: 바닥 50px을 제외한 나머지 전체가 당근밭, 그 중 왼쪽 20%만 잡초.

```css
#garden {
  display: grid;
  grid-template-columns: 20% 80%;
  grid-template-rows: 1fr 50px;
}
```

- 열: 왼쪽 20%(잡초) / 오른쪽 80%(당근)
- 행: 위쪽 `1fr`(남는 공간 전부 = 당근+잡초 영역) / 아래쪽 `50px`(제외 영역)

지금까지 배운 개념(퍼센트, fr, px 혼합) 중 필요한 것만 골라 쓰면 되는, 사실상 20~27단계의 요약 같은 마무리 문제였다.
