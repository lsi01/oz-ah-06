콘솔창 사칙연산 계산기

계산은 페이지가 아니라 개발자도구 콘솔에서 실행합니다.

  1. 콘솔 열기 — Windows: F12 / Mac: Option + Command + I
  2. start() 입력 → 계산식을 물어봅니다
  3. start("1 + 2 * 3") 처럼 바로 전달할 수도 있습니다
  4. calculate("2*3+4") 는 결과값(10)만 반환합니다
  5. runExamples() 로 여러 예시를 한 번에 확인합니다

규칙

  • + - * / 사칙연산
  • *, / 를 +, - 보다 먼저 계산
  • 피연산자 개수 제한 없음 — 긴 계산식도 처리
  • 공백은 있어도 없어도 인식: 1 + 2 = 1+2
  • 소수 지원: 1.5 * 2 → 3
